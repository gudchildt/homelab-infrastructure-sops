
# Proxmox Networking

Standard Operating Procedures (SOPs) for configuring, securing, maintaining, and troubleshooting networking services on Proxmox Virtual Environment (VE).

## Documentation

### Secure Remote Access

- [Tailscale VPN Installation and Automatic Reconnection](./Proxmox_Tailscale_Installation_Auto_Reconnect_SOP.md)

## Scope

- Secure remote administration
- Virtual Private Network (VPN) connectivity
- Network configuration
- Service monitoring
- Connectivity troubleshooting

## Documentation Standards

All procedures are designed to be:

- Reproducible and clearly documented
- Suitable for technical administrators
- Security-conscious
- Verified using appropriate system commands
- Free of private infrastructure identifiers

## Security Notice

Always review commands before executing them in production environments. Never publish credentials, authentication tokens, private configuration files, or sensitive infrastructure information.
